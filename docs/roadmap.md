# Roadmap d'exécution

## Phase 0 — Discovery (1 à 2 semaines)
- Interviews utilisateurs ciblées (design/PM/engineering).
- Analyse de 5 workflows clés (atelier, rétro, mapping, wireframe, review).
- Définition des métriques north-star.

## Phase 1 — MVP collaboratif (6 à 8 semaines)
- Auth + workspace + création de board.
- Canvas infini + objets de base + manipulation.
- Sync live CRDT + curseurs + présence.
- Permissions simples + partage lien.
- Undo/redo + autosave.

## Phase 2 — Productivité (4 à 6 semaines)
- Templates.
- Commentaires en thread.
- Export PNG/PDF.
- Mode présentation minimal.

## Phase 3 — Scale & Enterprise (8+ semaines)
- SSO/SAML, audit logs, rôles avancés.
- Perf tuning gros boards.
- API publique + webhooks.
- Intégrations (Jira/Confluence/Slack).

## Décision clé
Pour aller vite sans dette critique: livrer d'abord la qualité de sync et la fluidité canvas, puis enrichir les fonctionnalités.
